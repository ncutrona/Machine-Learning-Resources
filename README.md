# Machine Learning: A Mathematical Approach

## Overview

This repository contains a collection of learning modules designed to introduce fundamental concepts in machine learning from a rigorous mathematical perspective. The intended audience is advanced undergraduate students, beginning graduate students, and anyone with a strong mathematical background interested in understanding the theoretical foundations of machine learning.

Many introductory machine learning resources emphasize high-level intuition and practical implementation while omitting mathematical details. For students trained in mathematics, this approach can be frustrating due to imprecise notation, omitted derivations, and a general lack of mathematical rigor.

The goal of this repository is to bridge that gap by presenting machine learning methods with precise definitions, detailed mathematical derivations, and implementations in Python.

## Learning Modules

The following modules are currently being developed:

1. **Linear Regression** — Least squares, optimization, and the mathematical foundations of regression.
2. **Principal Component Analysis (PCA)** — Orthogonal projections, covariance matrices, eigenvalue decompositions, and dimensionality reduction.
3. **Gaussian Mixture Models (GMMs)** — Multivariate Gaussian distributions, maximum likelihood estimation, and the expectation-maximization algorithm.
4. **Support Vector Machines (SVMs)** — Convex optimization, separating hyperplanes, duality, and kernel methods.

Each module aims to develop the underlying mathematics carefully before implementing the corresponding algorithms in Python, with an emphasis on understanding rather than simply applying existing machine learning libraries.

## Prerequisites

Readers should be comfortable with the following mathematical subjects:

- **Multivariable Calculus**
- **Functional Analysis** 
- **Measure-Theoretic Probability Theory** 


A background in machine learning is not required.
